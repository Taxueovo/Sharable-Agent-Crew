## [0.1.0] - 2026-08-14

Initial public release.

### Added

- **Custom team building** — one Planner plus any number of Workers, each with
  a user-defined name, responsibility, and way of working
- **Explicit collaboration conversation** — Planning → Working →
  Discussion/Review → Final summary, with mid-run "replan" intervention
- **Controlled evolution** — the Planner proposes improvements to agent
  responsibilities after a run; applied to the draft only, never automatically
- **Read-only sharing** — publish a version and share a link plus access code;
  recipients can run the team but the architecture stays read-only
- **Admin mode** — list, deactivate, or permanently delete any version
- **Run history** — conversations are kept and can be continued with full
  context
- **Task attachments** — images, Word, Excel, CSV, and text files, with
  size limits and extraction
- **One-click local launch** — no system Node.js or admin setup required on
  Windows
- Tests for the rendered UI, MIT license, contributing guide, code of conduct,
  and security policy
